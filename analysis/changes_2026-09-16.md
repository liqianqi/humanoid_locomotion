## 1. `assets/rsx/urdf/asm1.SLDASM.urdf`

| 改动 | 原因 |
|---|---|
| `leg_r4_joint` axis `0 0 1` → `0 0 -1` | 折算到 base 坐标系后左膝轴 +Y、右膝 −Y。膝限位 [−10°, 130°] 是"屈膝为正"语义，只有左膝满足。翻转后两腿同角度即对称，`(0.15, 0.30, −0.15)` 下两脚 x 范围完全一致。 |
| `leg_l5_Link` / `leg_r5_Link` 各增加一个 box 碰撞体（0.0953×0.020×0.0678 m，底面与网格最低点齐平，保留原网格碰撞） | STL 脚底是船形：1 mm 内平坦区只有 6 cm，脚跟/脚尖高 4–8 mm，曲率半径 ≈0.18 m < 质心高 0.37 m。仿真中所有关节角不变、整机绕脚底滚动前倾，关节 PD 无法感知。平底盒使零动作可站立。 |

部署时需核对右膝电机的实际正方向。

## 2. `scripts/humanoid_locomotion/rsx.py`

| 改动 | 原因 |
|---|---|
| 默认姿态 `(0.15, 0.30, −0.15)` → `(0.13, 0.40, −0.27)` | 保持 `hip − knee − ankle = 0`（机身水平），质心落在脚底盒中心附近。探针：0.10/−0.30 前倾 +0.065 rad，0.15/−0.25 后倾 −0.05 rad，0.13/−0.27 ≈ 水平。 |
| 出生高度 `0.36` → `0.371` | 新姿态脚底最低点在 base 下 0.3674 m，留 4 mm 间隙；原值脚底穿地 9 mm。 |
| 三组执行器加 `armature=0.01` | `DCMotorCfg` 是显式 PD（每 5 ms 步施加力矩）。连杆仅 0.12–0.2 kg，\(K_d\,dt/I \approx 27 \gg 2\)，落地 2 步内关节速度达 12–19 rad/s、力矩全部饱和抖振。G1 同样用 0.01。加入后力矩 <4 N·m 且左右对称。 |
| 踝 `stiffness` 20 → 40 | 机身绕踝的重力负刚度 \(mgh/2 \approx 23\) N·m/rad，20 低于此值，静态即不稳定。 |

未改：`effort_limit` 11/7/5 与 `saturation_effort` 36/17/14 并存，实际上限就是 11/7/5，需确认是否有意。
